# Luminus AI Energy Assistant

This is a multi-agent AI system built using **Agentarium** and **Langflow**, designed to assist Luminus customers with:
- **Billing questions** (e.g., "Why is my bill so high?")
- **Energy usage insights** (e.g., "What is my past energy consumption?")
- **Energy-saving advice** (e.g., "How can I reduce my energy bill?")
